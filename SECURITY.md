# Security

The extension reads the conversations of the assistants it works on. A flaw
in it can therefore expose what people write to their AI: please report it
privately, never in a public issue.

## Reporting a flaw

Use GitHub's private reporting: the "Security" tab of this repository, then
"Report a vulnerability". Say what you found, on which site, and how to
reproduce it.

You will get an answer within seven days. Once the fix is published on the
Chrome Web Store, the report can be made public, with your name if you wish.

## What counts

- any way for a site, another extension or a third party to obtain the text
  of a conversation, or the figures the extension keeps;
- the extension sending anything over the network (it must send nothing);
- the extension breaking an assistant's page, or changing a message without
  a click from the person.

## Versions

Only the latest version published on the Chrome Web Store is maintained.
